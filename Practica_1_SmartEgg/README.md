# Práctica 1 — SmartEgg

Para la Práctica 1 del curso Arquitectura de Computadoras y Ensambladores 2 desarrollaremos SmartEgg, una propuesta de incubadora inteligente IoT.

## Descripción

Nuestro objetivo es construir un prototipo que mida las condiciones dentro de una incubadora y controle sus componentes de forma automática. El sistema deberá mantener la temperatura y la humedad dentro de los rangos establecidos, realizar la rotación periódica de los huevos y alertarnos cuando existan condiciones inadecuadas.

También enviaremos los datos al computador mediante comunicación serial y permitiremos su consulta desde una aplicación web.

## Estado

Nuestro proyecto se encuentra en desarrollo. Documentaremos las tecnologías, los componentes y la estructura definitiva cuando los seleccionemos e implementemos.
