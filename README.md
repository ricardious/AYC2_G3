# Arquitectura de Computadoras y Ensambladores 2 — Grupo 3

Repositorio del Grupo 3 para el curso **Arquitectura de Computadoras y Ensambladores 2**, sección A, de la Facultad de Ingeniería de la Universidad de San Carlos de Guatemala. Aquí reunimos la Práctica 1, el Proyecto 1 y el Proyecto 2 de SmartEgg.
